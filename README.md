# بيئة التعلم الشخصية: التفاعل والحضور في بيئات التعلم الرقمية

مشروع جماعي لمقرر **التقنية في بيئات التعلم** – برنامج الماجستير المهني في تصميم التعلم والتكنولوجيا، جامعة الأميرة نورة بنت عبدالرحمن.

## محتوى المستودع

| الملف | الوصف |
|---|---|
| `index.html` | موقع البيئة: الأهداف الستة وربطها بالأعضاء، ومصادر كل هدف بنفس المعايير، والأدوات والشبكة المهنية والخطة |
| `docs/بيئة التعلم الشخصية - التفاعل والحضور.docx` | ملف الوورد المطابق للموقع |

## المعيار الموحّد لكل هدف

1. أربعة مصادر مكتوبة: بحث علمي، ومقال أكاديمي، ودليل تطبيقي، ومرجع رسمي
2. مصدران مرئيان (ندوة أو حلقة نقاش أو مقطع)
3. حلقة بودكاست
4. دورتان تدريبيتان أو ورشتا عمل
5. شهادة مهنية مع الجهة والشروط ومتطلبات الالتحاق
